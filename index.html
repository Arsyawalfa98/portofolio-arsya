01 — Tentang

Membangun sistem, dari arsitektur yang bersih.

Saya seorang Software Engineer yang penuh semangat dengan 5+ tahun pengalaman membangun aplikasi web dan sistem institusi yang andal di sektor pendidikan dan bisnis. Fondasi inti saya ada pada PHP (Laravel) dan JavaScript.

Fokus terbaru saya bergeser ke ekosistem Go — secara mandiri membangun REST API yang terstruktur di atas clean architecture menggunakan Chi, pgx, dan sqlc. Saya developer yang sangat adaptif, berkembang lewat pembelajaran berkelanjutan, dan rutin memanfaatkan AI-assisted tools untuk mempercepat pengembangan dan mengambil keputusan desain yang lebih baik.

Berkomitmen pada full ownership atas apa yang saya bangun, saya ingin terus berkembang dan berkontribusi secara bermakna dalam tim engineering yang berpikiran maju.

P.04

REST API dengan Go (Golang)

REST API Go dengan arsitektur berlapis Handler → Service → Repository menerapkan Clean Architecture & DDD. Dibangun di atas Chi Router dengan PostgreSQL via pgxpool, query type-safe dengan sqlc, konfigurasi & logging via Viper dan Zerolog. Autentikasi dual-token JWT (RS256) dengan Redis denylist, dikemas Docker Compose dan alur Git Flow.
